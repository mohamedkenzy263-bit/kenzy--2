تقرير عن JavaScript

المقدمة

تعد لغه JavaScript من اهم لغات البرمجية في عالم التطوير اللي احنا فية فهي اللغة التي تمنح صفحات الويب الحياة و التفاعل ويهدف التقرير الي التعرف بلغه JavaScript ونشاتها واهميت استخدمها في حياتنا

الموضوع

ما هي لغة JavaScript هي لغة برمجة عالية المستوى تستخدم بشكل أساسي في المتصفحات لإضافة التفاعل والديناميكية إلى صفحات الويب تعمل إلى جانب لغتي HTML وCSS، حيث تتولى التحكم في سلوك العناصر والاستجابة لأحداث المستخدم مثل النقر والكتابة

نبذة تاريخية ظهرت JavaScript عام 1995 على يد "برندان آيخ" في شركة Netscape وكانت تُعرف سابقًا باسم LiveScript قبل أن يتم تغيير اسمها. وفي عام 1997 تم توحيدها ضمن معيار ECMAScript الذي تُشرف عليه منظمة ECMA الدولية

أهم استخدامات JavaScript

  • إضافة التفاعلية لصفحات الويب (أزرار، نوافذ منبثقة، تحقق من النماذج)
  • بناء تطبيقات الويب الحديثة باستخدام مكتبات مثل React وVue
  • تطوير تطبيقات الهواتف عبر React Native
  • تطوير الخوادم والخدمات الخلفية باستخدام Node.js
  • إنشاء الألعاب والرسوم المتحركة في المتصفح

صوره عن اللغه

الخاصية JavaScript Python
بيئة التشغيل الأساسية المتصفح والخادم (Node.js) الخادم وسطح المكتب
مجال الاستخدام الأشهر تطوير الويب الذكاء الاصطناعي وتحليل البيانات
التفاعل مع صفحات الويب مباشر وأصيل عبر أطر عمل خارجية

الخاتمة

في الختام، تُعد JavaScript ركيزة أساسية في تطوير الويب الحديث، ولا تكاد تخلو أي صفحة تفاعلية من استخدامها. ولذلك يُنصح كل مطور ويب بإتقانها إلى جانب HTML وCSS لبناء تطبيقات متكاملة.
